# CLAUDE.md

## Loyiha
Dilshodbek Ergashev — Meta Ads targetologi — uchun bitta sahifali vizitka sayt.
Maqsad: mijoz natijalarni ko'rib, telefon yoki Telegram orqali bog'lansin.
Auditoriya: O'zbekistondagi biznes egalari. Sayt tili — faqat o'zbekcha.
Fayllar: `index.html`, `styles.css`, `script.js`, `assets/`. Deploy — Netlify (drag-and-drop zip).

## Uslub
- Minimalist, professional, "education" ohangi. Gradient, ortiqcha bezak va emoji yo'q.
- Ranglar faqat `:root` tokenlari orqali: `--accent` (to'q ko'k), `--bg` (krem oq), `--ink`, `--muted`, `--line`.
- Sarlavha — Georgia (serif), matn — tizim sans-serif. Tashqi shrift yuklanmaydi.
- Matn qisqa va dalilga asoslangan: raqam, natija, aniq fakt. Bo'sh maqtov yo'q.
- O'zbekcha belgilar to'g'ri yoziladi: o', g', ta'lim.

## Texnik chegaralar
- Faqat statik fayllar: build qadami, npm, bundler yo'q.
- Framework va CDN kutubxonalari ishlatilmaydi (React, Tailwind, jQuery, Bootstrap).
- JS minimal: u o'chsa ham sayt to'liq o'qiladigan holatda qolsin.
- Hamma fayl UTF-8, `<html lang="uz">`.
- 375px enlikda gorizontal scroll bo'lmasin. Dark mode tokenlari saqlanadi.

## Ma'lumot
Lead soni, budjet, ROAS kabi raqamlar faqat rezyume va portfolio PDF'laridan olinadi.
Raqam, mijoz nomi yoki natija o'ylab topilmaydi — noaniq joyda so'ra.

## Ish tartibi
1. O'zgartirishdan oldin rejani 2-3 qatorda ayt.
2. Kichik qadamlar bilan ishla; bitta so'rovda hamma narsani qayta yozma.
3. Har o'zgarishdan keyin brauzerda desktop va 375px mobilda tekshir.
4. Tekshiruv tugagach lokal serverni to'xtat — foydalanuvchiga localhost havolasi berilmaydi.
5. Javoblar o'zbek tilida va qisqa.

## Xavfsizlik
Parol, API kalit, token yoki shaxsiy hujjat ma'lumotlari bu papkaga yozilmaydi.
